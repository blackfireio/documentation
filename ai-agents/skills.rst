The Blackfire agent skills
==========================

The Blackfire skills are available from the `blackfireio/skills
<https://github.com/blackfireio/skills>`_ repository.

Installing the skill
--------------------

.. code-block:: bash

    npx skills add blackfireio/skills

With Claude Code, as a plugin:

.. code-block:: text

    /plugin marketplace add blackfireio/skills
    /plugin install blackfire@blackfire
